# vkboard Service Flow Map

Публичная интерактивная карта пути информации через сервис `vkboard`.

Сайт: <https://iiseng.github.io/vkboard-service-flow/>

Новая адаптивная версия для параллельной продуктовой приёмки:
<https://iiseng.github.io/vkboard-service-flow/v2/>. Корневой адрес сохраняет
первую версию без изменений.

Репозиторий намеренно содержит только статическую страницу и минимальные
проверки публикации. Здесь нет backend, production-кода, исходных данных,
переменных окружения, токенов или API-ключей.

Публикуемая папка — `web/service-flow/`: первая версия находится в корне, вторая
— в строго разрешённом каталоге `v2/`. Перед каждым deployment автоматическая
проверка независимо валидирует оба набора и отклоняет лишние файлы и каталоги,
внешние URL, секреты, symlink и расширение браузерных возможностей без явного
review.
