# vkboard Service Flow Map

Публичная интерактивная карта пути информации через сервис `vkboard`.

Сайт: <https://iiseng.github.io/vkboard-service-flow/>

Новая адаптивная версия для параллельной продуктовой приёмки:
<https://iiseng.github.io/vkboard-service-flow/v2/>. Корневой адрес сохраняет
первую версию без изменений.

Третья версия с единым скроллящимся фоном и естественным вертикальным маршрутом:
<https://iiseng.github.io/vkboard-service-flow/v3/>. Первая и вторая версии
сохраняются для сравнения.

Четвёртая версия с футуристическим погружением в глубину аналитического
конвейера: <https://iiseng.github.io/vkboard-service-flow/v4/>. Предыдущие
версии сохраняются без изменений.

Репозиторий намеренно содержит только статическую страницу и минимальные
проверки публикации. Здесь нет backend, production-кода, исходных данных,
переменных окружения, токенов или API-ключей.

Публикуемая папка — `web/service-flow/`: первая версия находится в корне, а
остальные — в строго разрешённых каталогах `v2/`, `v3/` и `v4/`. Перед каждым
deployment автоматическая проверка независимо валидирует все четыре набора и
отклоняет лишние файлы и каталоги, внешние URL, секреты, symlink и расширение
браузерных возможностей без явного review.
